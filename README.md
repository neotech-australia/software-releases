# software-releases
Official releases and downloads for NeoGT software applications, tools, and utilities.

## Collector Installer

`collector-installer/` contains the public Tiltmeter collector installer source and build scripts.

## Device Configurator

`device-configurator/` contains the public NeoGT LoRaWAN device configurator source and build scripts.

## Binaries

`bin/` contains versioned release artifacts copied by each project's build scripts.
